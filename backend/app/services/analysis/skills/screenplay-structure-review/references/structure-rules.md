# 结构审阅清单

## 场景推进

- 记录场景进入时的目标或压力、阻碍如何升级、离开时发生了什么不可忽略的变化。
- 按发生顺序还原动作与反应，检查重复的策略是否真的提高了压力；不凭场景长度判断节奏。
- 结果可以是成功但带来新代价、失败并恶化、目标被重新定义或迫使人物选择；没有变化时明确写出。
- 情绪反应场应把上一个结果转化为困境和决定，为下一步行动建立因果，而不是简单复述。

## 转折与兑现

- 转折必须改变人物可用的信息、策略、关系或风险，不以突发事件的表面强度代替结构作用。
- 检查重要信息和道具的首次出现、人物何时得知、后续如何使用与兑现。
- 对矛盾只描述文本可验证的两端。

## 节奏与建议

- 比较冲突升级、转折密度、重复信息和连续同强度的场景，定位节奏问题的起止位置。
- 修改建议优先采用合并、前移、后移、删减重复、强化选择或补足因果等可执行动作，写清修改后要达到的结构效果。
- 保留作者已有的故事目标，不用单一结构模板取代文本本身。

## 叙事事实与生产的边界

- 场景中的人物、地点、道具和可视化动作是后续生产可以确认的事实线索，不写成已经确认的资产或镜头。
- 必要事实没有被后续场景或动作承接时，写成 `priority_revisions`，说明缺口和影响。
- 连续性问题区分信息缺失、文本矛盾和有意留白；只有前两者证据充分时才提出修改建议。
