# 场景边界与提炼规范

## 一、场景定义

一个场景由相邻分析分镜归并而成，同时满足大部分条件：

- 相邻镜头处于可理解的连续时间范围；
- 空间关系稳定，或交叉剪辑仍在完成同一连续事件；
- 主体和主要事件目标没有重置；
- 构图、光色、镜头运动或画面材质遵循一组相对稳定的视觉规则；
- 这些镜头共同完成一个主要叙事任务。

单个分析分镜可以独立成场，不因数量少而与相邻段落强行合并。连续长镜头跨越空间区域或事件任务时，先建立 `continuous` 分镜边界，再判断是否换场。

## 二、边界证据

按强到弱检查：

1. **空间重置**：地点、室内外、舞台或界面层级、空间布局发生明确变化。
2. **时间重置**：昼夜、天气、服装或道具状态、进度画面、明确的时间卡发生变化。
3. **事件重置**：上一任务已完成或中断，新的主体或行动目标开始。
4. **视觉重置**：画幅、色调、媒介形态、运动规则或信息密度形成新的稳定簇。
5. **段落标记**：标题卡、黑场、建立镜头、进出场、蒙太奇起止或明显的节奏停顿。

只有单个 Cut、轻微景别变化或同一动作的反打，通常不足以建立新场景。

## 三、字段写法

- `index` 从 1 连续递增。
- `title`：写该场完成的事，8–20 字，不用“场景一”或空泛情绪词。
- `location`：可见空间，例如“白墙会议室”“夜间街道”“深色产品演示台”；无法确认时写“空间无法确认”，不猜地名。
- `description`：2–4 句的小段落，依次写开始状态、事件推进和结束状态。
- `narrative_function`：一句话写清该场在全片中的任务，以及进场和退场的依据。
- `visual_rules`：2–6 条，每条是一条可以照做的约束，覆盖构图与机位、光色、运动、空间或关键资产中实际相关的项。
- `continuity_risks`：每条写成完整句子，具体到人物朝向、道具状态、屏幕文字、空间位置、服装、光线或动作衔接；不写“注意保持一致”。没有明确风险时返回空数组。
- `evidence_shot_ids`：按时间顺序列出本场全部镜头，不只选代表镜头。

## 四、归并步骤

1. 从第一个分镜开始建立当前场景。
2. 对每个相邻镜头比较空间、时间、事件目标和视觉规则。
3. 变化只是覆盖角度、反应镜头、插入特写或同一连续动作时，继续归并。
4. 至少一个强边界成立，或多个弱边界共同表明任务已经重置时，结束当前场景。
5. 完成后反向检查：相邻两场能否用一句话说明“为什么这里换场”；说不出就合并。

## 五、验收

- 各场 `evidence_shot_ids` 首尾相接，合计恰好覆盖全部镜头一次。
- 场景时间由证据镜头派生，不自行返回或估算。
- 每场只有一个主要任务，标题、描述和作用不互相重复。
- 同地点回返、蒙太奇和交叉剪辑按连续时间段处理，并说明呼应关系。
- 视觉规则足以指导复刻，连续性风险足以供人工验收。
