# 导演拉片方法

## 一、逐镜判读

对每个分析分镜按以下顺序判读，后一层不得掩盖前一层的不确定性。

1. **边界与状态**：边界是硬切、渐变、遮挡等物理编辑，还是无编辑但主体任务、空间区域、动作阶段、信息状态或构图任务已经重置的连续节拍。分别观察起始、代表和结束画面。
2. **调度**：主体从哪里开始、做了什么、在哪里结束；多主体时记录距离、朝向、遮挡、前后景和权力位置的变化。调度要解释为人物策略，例如靠近施压、转身拒绝、占住出口。
3. **摄影与美术**：景别、可见角度、构图重心、层次、负空间、光源方向、明暗关系、主色和关键道具。焦段、灯具和曝光参数不能仅凭画面断言。
4. **剪辑关系**：本镜如何承接上一镜、交给下一镜；动作匹配、视线匹配、运动方向、图形或色彩匹配、反应镜头、插入镜头、有意跳切。已经切镜时，新镜是否在景别、角度或人物关系上带来至少一项可见变化。
5. **叙事节拍**：本镜承担的一个首要任务，例如建立空间、交代或扣住信息、触发选择、展示反应、升级冲突、释放压力、收束段落。

## 二、字段写法

- `description`：一到两句连贯的中文，依次交代主体与动作、空间与构图、光线与色彩、起止状态，通常 60–150 字。只写画面可证实的内容，不加“主体与动作：”这类标签。例如：“女主从画面左侧走到窗边停下，背对镜头；窗框把她压在画面右下三分之一，室内只留窗外冷光；镜头从全身固定到她停步为止。”
- `narrative_function`：一句话写清本镜完成的节拍、与前后镜的关系和判断依据。例如：“让观众先于她看到门外的人影，为下一镜她回头的反应铺垫。”不写“推进剧情”“营造氛围”。
- `shot_size`、`camera_motion`、`transition_in` 使用 Schema 枚举；景别或运动在镜内明显变化时用 `mixed`。
- `visual_tags` 不进入报告正文，用于检索和比较。优先使用 `angle:`、`composition:`、`lighting:`、`palette:`、`continuity:`、`rhythm:` 前缀，每项短而具体。
- `highlight_score`：1 = 只维持连续，2 = 提供辅助信息，3 = 完成明确节拍，4 = 关键转折或强表达，5 = 不可替代的核心画面。不预测播放量或转化。

## 三、序列检查

1. 第一镜是否建立了足够的空间；若有意延迟建立，说明它的作用。
2. 相邻镜头的人物朝向、运动方向、道具位置、服装和光线方向是否一致；有画面依据的变化写成状态变化。
3. 同轴、同景别的切换是否造成跳动；经验法则只作提示，不写成绝对错误。
4. 动作开始于上一镜、完成于下一镜时，分别写清两镜各承担哪一段。
5. 节奏在哪里改变：镜长簇、静转动、全景转特写、色彩或亮度突变、信息密度变化。

## 四、复刻与修改建议

- `production_advice.summary` 用一段话回答：哪条视觉规则最该保留、核心节拍如何组织、最大的连续性风险在哪里。
- `production_advice.priority_shot_ids` 列出真实分镜 ID，报告会把它们显示为“分镜 004”这样的序号。
- `recommended_extensions` 每条是一个完整句子：涉及哪几个分镜、必须保留的约束、要做的动作、完成后如何验收。正文里指代分镜写“分镜 004”，不写内部 ID。例如：“复刻分镜 004–006 时，保持人物始终面向画面右侧、桌上红色杯子位置不变；先拍固定机位的建立镜头，再补反应特写；完成后检查切换前后视线与杯子位置一致。”

## 五、交付自检

- 时间线从 0 连续覆盖到权威时长，物理编辑与连续节拍都经过画面复核。
- 每镜的描述、叙事功能和标签互相补充，不重复同一句话。
- 空间、调度、镜头动机、剪辑关系、节奏和连续性六个方面都检查过。
- 摘要、高光、资产和建议引用的分镜都存在；没有音频证据的判断已作为局限说明。
