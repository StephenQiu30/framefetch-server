# 高光候选量表

## 一、五维评分

每项 0–4 分，只依据可见画面：

1. **视觉显著性**：构图、动作、尺度、色彩或状态变化是否形成清晰焦点。
2. **信息或情绪转折**：是否出现可见的新信息、选择、结果、反应或关系变化。
3. **上下文独立性**：脱离前文后核心画面是否仍可理解，需要多少前置镜头。
4. **可剪辑性**：是否有完整的进入点、核心动作和退出点，适合单独回看或编入预告。
5. **复用与连续性**：是否有代表性，且没有严重遮挡、文字残缺、动作中断或状态冲突。

内部总分 0–20，输出 `score` 为总分 × 5（0–100）。分镜的 `highlight_score` 按总分换算：0–4 → 1，5–8 → 2，9–12 → 3，13–16 → 4，17–20 → 5。分数只用于同一视频内排序，不写成算法预测、平台表现或用户偏好。

## 二、候选边界

- **进入点**：主体、空间或问题已经可理解。
- **核心点**：包含最关键的可见变化或构图。
- **退出点**：动作结果、反应或视觉停顿已经完成。
- 转折依赖两个相邻分镜时合为一个高光并引用全部证据分镜；中间夹着无关段落时拆开。
- 进入和退出可以落在物理编辑边界，也可以落在连续长镜头内已完成的节拍边界。

## 三、去重与多样性

两个候选的主体、动作、构图、信息任务和节奏作用大体相同时，只保留总分更高的一项。最终候选尽量覆盖不同用途，例如建立世界、人物反应、动作峰值、信息揭示、视觉转场或收束画面；不为类别齐全保留弱候选。

## 四、字段写法

- `description`：2–3 句，写清片段的起点、变化和结果。
- `reason`：一到两句完整的话，说明它在量表上的主要优势、与相似候选的差别，以及使用前需要确认的风险。例如：“整段只有这一处出现完整的‘拿起—失手—落地’动作，前后都有停顿可以干净裁切；比开场的同类动作更清晰，但落地瞬间有运动模糊，用作封面前需逐帧确认。”
- 不写“有传播力”“很震撼”“情绪拉满”这类循环论证；没有可访问音频时，不以对白金句、节拍或音效作为理由。
