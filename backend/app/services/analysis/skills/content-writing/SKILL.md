# Purpose

## 文体选择

article：建立中心判断或读者问题，优先连续自然段；小标题和列表按内容决定，不写成事实核查报告。
post：抓住一个具体信息或感受，允许一句话、无标题、无结尾；不把短帖扩写成迷你文章。
guide：让读者完成实际操作，顺序确有依赖时使用步骤；参数、错误恢复和前置条件只在操作需要时出现，不为了追求“文章感”破坏说明的清楚性。

# Plan

先确定读者读完能理解、判断或完成什么，再从材料中选择一个足以支持的写作角度。用一句话说清文章的主张；安排信息怎样逐步展开，不把段落计划直接当小标题。可以从具体细节、矛盾、问题或结果进入；没有故事材料时不编故事。记录要读的材料片段或需要复看的画面，舍弃与主张无关的流程、参数和重复说明。

# Draft

按选定角度写一篇读者愿意读完的文章。每个段落带来新的事实、理解或推进，连接的是意思，不是步骤序号。只在真正转题时用小标题；可以全文没有小标题。长短句和段落长度随内容变化，不强求三段式、每节同样长、固定导语、要点和总结。

把具体对象作为句子主语。材料已说明的事情可以直接讲；只有归属影响可信度时才说明是谁说的。避免每段重复“片中介绍”“画面显示”“这条记录说明”。对未经验证的来源说法保留归属，但不要将整篇写成对证据的逐条解说。与读者决定有关的限制自然放在相应陈述附近，纯编辑核查留在 evidence 或 limitations 中，不在每段末尾加一次免责声明。

采用作者范文的表达偏好，保留恰当口语、术语和个人节奏，不虚构第一人称经历。不堆万能判断、套话或人为对立。结束在文章意思已经完成的地方，可以停在一个细节、可用判断或下一步，不重复全文。结构字段只是容器，不是文章大纲；可选标题、导语、结尾和要点不需要填满。

# Review

独立以读者身份读成稿，再对照原材料。先检查文章有没有一个值得阅读的问题，以及各段是否真的推进了它；将按截图/时间顺序复述、连续解释证据、参数罗列和反复留边界判断为结构或表达问题。检查事实是否超出来源、来源说法是否被误写成实际验证、作者范文是否被借用为事实。只有具体影响采用的问题才写 findings，无问题可以为空。

对每个重大问题写明位置、原因及修正目标，保留已有好句和事实。证据不足但可以缩小陈述时提出该修改；核心问题无法回答时标为缺材料。审校记录不进入正文。复核时检查指出的问题是否解决，以及修订是否引入了新事实或破坏作者表达。
