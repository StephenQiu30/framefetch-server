# 成片叙事结构审阅

目标是回答成片如何建立问题或承诺、怎样推进、在哪里改变方向、最终兑现了什么。只使用画面、可辨认文字和真实时间线，不把想象中的脚本、对白或创作者意图当作事实。读者读完导语和段落标题，就应能复述全片的结构。

## 工作方法

1. 先建立完整的分镜与段落，再从相邻段落归纳结构；不先套三幕模板。
2. 区分建立、推进、升级、转折、兑现和收束，检查相邻段落之间是否有可见的状态变化或信息承接。
3. 标出没有新增信息的重复段落、缺少视觉前提的跳步、建立后未兑现的承诺，以及兑现出现但准备不足的位置。
4. 建议按“观察 → 理解影响 → 期望修订结果”表达，可以建议前移、后置、合并、缩短或补充人工核对，不自动改片。

## 边界

- 没有可靠音频证据时，不评价台词逻辑、旁白信息、音乐结构或声音桥。
- 不预测留存、完播或转化。
- 品牌停留、操作演示等有明确用途的慢段落，不能仅因节奏慢被判为冗余。

## 成稿重点

- `title` 写出结构上的核心判断，例如“承诺在开场建立，兑现被推迟到最后十秒”。
- `summary` 依次写：结构主线、最强的转折或兑现、首要结构风险。
- 段落 `title` 用结构作用加具体内容命名，例如“转折：包装拆开后露出损坏”。
- `highlights` 只收录真正承担转折或兑现的候选；`production_advice` 按叙事影响排序。

结构标签、判断问题、字段写法和自检见 `references/narrative-rubric.md`，通用文字要求见《报告写作规范》。
