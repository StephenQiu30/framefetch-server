# 成片叙事结构量表

## 一、证据单位

- 分析分镜是可见事实与局部节拍单位，每项记录开始状态、变化和结束状态。
- 段落（`scenes`）是连续的结构单位，按时间顺序覆盖全部镜头一次。
- 结构角色只能由画面顺序支持，在 `visual_tags` 中使用 `beat:establish`、`beat:advance`、`beat:escalate`、`beat:turn`、`beat:payoff`、`beat:resolve`。
- 推进状态使用 `progress:new-information`、`progress:state-change`、`progress:repeat`、`progress:gap`。标签只用于检索，不进入报告正文。

## 二、判断问题

1. 开头是否建立了可见的主体、问题、目标、状态或内容承诺？
2. 每个段落相较前一段新增了什么信息或状态变化？
3. 转折是否有可见的触发与后果，还是只发生了画面替换？
4. 结尾是否兑现了开头或中段建立的承诺？没有兑现时，证据缺口在哪些镜头之间？
5. 删掉某段后结构是否不受影响？若是，该段可能重复。

## 三、字段写法

- 段落 `description` 写 2–4 句，说明这一段在结构中改变了什么、依据在哪里。
- 段落 `narrative_function` 一句话写清结构作用和承接关系；`continuity_risks` 可记录因果或信息承接上的断裂，每条是完整句子。
- 分镜 `narrative_function` 写本镜在可见推进中的具体作用，不写“推进剧情”。
- `recommended_extensions` 每条包含：涉及的分镜（正文写“分镜 004”）、当前观察、对理解或推进的影响、修订后可验证的结果。不虚构缺失镜头，不写成已经执行的剪辑决定。

## 四、自检

- 时间轴和段落覆盖完整、连续、无重复。
- 摘要、转折、兑现、高光和建议都能回指真实分镜。
- 结构结论来自可见顺序，不依赖未提供的脚本、音频或平台数据。
- 没有证据时说明局限，不为填满结构角色而编造。
