# 综合分析证据规范

## 一、三层证据链

1. **观察层**：分析分镜区间、边界类型、代表帧、可见主体、动作、构图、画面文字和状态变化。
2. **解释层**：镜头功能、段落转折、节奏、视觉模式和可能的表达效果。措辞写出依据，不把推断写成创作者的明确意图。
3. **建议层**：复刻、剪辑、生成或资产整理建议，必须落在观察层的对象上，并带可执行动作。

解释与观察冲突时以观察为准；证据不足时把结论降为保守描述，不用常识填补。

## 二、段落归纳

内容段落可由以下变化触发：空间或主体切换、视觉目标改变、信息密度变化、镜长簇变化、静动转换、色调重置或明确的转场卡。段落边界不等于每个 Cut。

- `scenes[].description` 写成 2–4 句的小段落：先说这一段做成了什么，再说依据和起止状态。
- `scenes[].narrative_function` 一句话写清这一段在全片中的任务，以及从上一段进入、向下一段交出的依据。
- `summary.evidence_shot_ids` 至少覆盖开端、中段关键转折和结尾，不只引用单一高光。

## 三、字段写法

- 分镜 `description` 用一到两句连贯的中文交代主体与动作、空间构图、光色和起止状态；`narrative_function` 一句话写清节拍与衔接。两者会进入报告表格，不加字段标签，不写内部 ID。
- `highlights[].reason` 用一两句说明它比同类候选强在哪里，以及使用前要确认什么。
- `assets[].description` 先写稳定特征，再写可见的状态变化和连续性风险。

## 四、覆盖矩阵

| 维度 | 最低要求 |
|---|---|
| 时间线 | 从 0 连续到权威时长；物理编辑与连续节拍不混淆 |
| 结构 | 每个主要段落有代表镜头 |
| 转折 | 关键变化有前后镜头证据 |
| 高光 | 理由可由画面证明，且不是全部镜头 |
| 资产 | 核心身份已合并，关键状态有证据 |
| 建议 | 每条包含对象、动作和验收条件 |

## 五、制作建议优先级

1. 是否承载核心叙事转折；
2. 是否建立风格或空间规则；
3. 是否可作为角色、场景或道具连续性的基准；
4. 是否存在复杂动作、遮挡、文字或状态变化风险；
5. 是否能在不依赖未知音频的情况下可靠复刻。

`production_advice.summary` 用一段话说明优先顺序背后的理由；`recommended_extensions` 每条是完整句子，正文中指代分镜写“分镜 004”，并写出验收结果。不编造成本、排期、平台效果、供应商能力或已完成的生产状态。
