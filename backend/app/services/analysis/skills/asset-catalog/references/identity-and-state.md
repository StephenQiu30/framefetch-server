# 资产身份与状态规范

## 一、身份归并顺序

对候选依次比较：

1. **稳定形态**：轮廓、结构、面部与发型、服装主件、空间布局、产品形状、Logo 图形或文字内容。
2. **上下文连续**：相邻镜头的动作、位置、手持关系和进出方向是否支持同一对象。
3. **区别特征**：颜色强调、纹理、破损、配件、标记、家具布局或界面结构。
4. **冲突证据**：两者同时出现在同一画面、结构明显不同，或状态变化无法由连续动作解释时，不合并。

角度、裁切、远近、景深、色温和短时遮挡通常不构成新身份。证据不足时使用“人物 A”“室内场景 A”“深色手持物”等保守标签。

## 二、字段写法

- `label`：稳定、中性、可检索的名称；同一资产全文只用这一个名称。
- `description`：2–3 句连贯的中文。先写稳定特征，再写可见的状态变化及其发生位置，最后写连续性风险；没有变化或风险时不硬写。例如：“银色金属外壳的保温杯，杯身有一道竖向划痕，杯盖为黑色。它在分镜 005 被打开，之后一直保持开盖状态。分镜 009 的远景里杯子位置从桌子左侧变到右侧，缺少移动过程。”
- 状态包括服装增减、污损破损、开合、内容更新、持有关系、灯光开启、空间布置变化等，只记录有画面证据的变化，不生成不存在的版本编号。
- `evidence_shot_ids` 至少覆盖首次清晰出现和关键状态；看不清身份的远景不能作为唯一证据。

## 三、证据等级

- **主证据**：清晰、无遮挡、能看见区别特征的镜头。
- **连续证据**：通过连续动作或空间关系支持同一身份的镜头。
- **弱证据**：远景、强遮挡、运动模糊、反光或只见局部的镜头。

每项资产至少有一条主证据；只有弱证据时，在描述中写明“不足以确认”，并避免具体命名。

## 四、类型边界

- `person`：可见人物的身份候选，不推断真实身份。
- `location`：有稳定空间布局的场景；同一地点的不同机位通常合并。
- `object`：道具、服饰配件、家具或通用物件。
- `product`：画面明确作为产品主体展示；无法确认时用 `object`。
- `logo`：独立的图形或品牌标记，只记录可见内容，不推断权属。
- `on_screen_text`：标题卡、字幕、界面文字或图形文字；内容更新可以写成状态变化。

## 五、完成检查

合并后按时间线再检查一遍：有没有一物多名、同名异物、首次出现时间错误、状态前后矛盾、证据分镜不存在或类型越界。
