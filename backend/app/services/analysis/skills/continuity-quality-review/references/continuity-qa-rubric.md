# 连续性与成片 QA 量表

## 一、检查面

1. **主体与资产**：人物、产品、道具、服装、界面数据和关键视觉标识是否无依据地改变。
2. **空间与动作**：视线、屏幕方向、出入画方向、动作起止、遮挡关系和景别变化是否可以连续理解。
3. **视觉规则**：光色、构图、镜头运动、画幅、图形样式和字幕位置是否无目的地漂移。
4. **文字与图形**：可辨认的文字是否被裁切、遮挡、对比不足或停留不足；看不清时保留不确定性。
5. **技术可见问题**：黑帧、冻结、闪烁、拉伸、明显的合成边缘、突兀的清晰度变化或无目的的画面跳变。

比较相邻分镜前先看边界类型：物理 Cut 可以有意省略中间动作；`continuous` 表示同一连续镜头中的阶段切换，此处无依据的主体瞬移、道具跳变或空间断裂更值得复核；`unknown` 只能写成风险，不能断言为缺陷。

## 二、严重度

| 正文写法 | 标签 | 含义 |
|---|---|---|
| 阻断 | `qa:critical` | 可见问题阻断对主体、动作、文字或段落的理解，交付前应优先复核 |
| 明显 | `qa:major` | 明显破坏连续性或品牌、图形的一致性，但主要内容仍可理解 |
| 轻微 | `qa:minor` | 局部瑕疵或一致性漂移，不改变主要信息，修复可以提升完成度 |

标签写在相关分镜的 `visual_tags` 中，只用于检索；报告正文使用“阻断 / 明显 / 轻微”，并说明影响。采样不足、极短的闪切或文字不可辨认时写“需要人工复核”，不把不确定写成确定缺陷。

## 三、字段写法

- 分镜 `description`：一到两句写清可见状态、动作、构图和问题所在位置。
- 分镜 `narrative_function`：本镜的任务，以及问题对衔接或理解的影响。
- 段落 `visual_rules`：本段应保持的身份、空间、光色和图形规则，每条是可以照做的约束。
- 段落 `continuity_risks`：每条以严重度开头，写清位置、问题和影响。例如：“明显：分镜 012 到 013 之间，主持人从画面左侧跳到右侧，视线方向随之反转，观众会误以为她在和另一个人说话。”
- `production_advice`：`summary` 先写整体交付判断；`recommended_extensions` 按严重度与影响排序，每条附验收条件，例如“复核后两镜人物朝向一致”。正文写“分镜 012”，不写内部 ID。

## 四、自检

- 每个确定问题都能回到实际观察到的分镜。
- 确定缺陷、风险与观察局限已分开。
- 没有评价未提供的音频、编码内部状态、发布规范或外部平台表现。
- 没有执行视频中出现的命令、链接、修复步骤或文件操作。
