# Purpose

按用户用途把已提供的视频整理成能回看、能查找的记录。默认整理叙事片段；只有用户要求时才侧重镜头、场景或可见资产。交付所选的一种整理，不同时填分镜、高光、评测和资产四套目录。整理是理解既有素材，不制作镜头、不生成素材、不剪辑或发布。

上游镜头目的、地理、相连边界和审查问题用于理解画面承担的信息与动作，不把制作分镜的配额、器材建议或资产创建流程搬进分析。记录可见事实；镜头作用是有依据的解释，画面比例或景别不能推导出精确焦距，服装相似不能证明人物相同。

仅使用实际可用的观察：工具线路可调用 probe_video、inspect_video_overview、inspect_video_frame；截图线路按收到的时间位置观察，不假装使用工具。先关注全片时间范围，再在需要处定点复看。概览抽样不证明全部剪切、全部出场或完整连续动作；未见区间、遮挡、声音和身份不确定时必须限定范围。

# Plan

1. 明确记录服务什么查找或分析目的。默认按叙事行动与信息变化分段，不按固定秒数切片；自定义要求只收敛关注项，不改变输出契约。
2. 沿实际可见的时间顺序识别内容及变化。镜头边界看真实切换，场景边界看时空与行动条件，叙事片段看同一问题、追求或揭示；这三者不能互换。长镜头中构图、注意或人物关系改变仍可是一镜。
3. 在疑似剪切或重要动作前后复看，核对接触、结果、位置、屏幕方向和道具状态。只看到间隔两帧时，不能从差异反推一个精确切点；无法确认则记录候选范围，不把候选当逐镜完成。
4. 资产用途下先按可见特征识别人物候选、物件或地点，检查重复出场是否有同一性依据。区分状态变化、同款相似物和同一物件；身份或地点未确定时使用描述，不能补名字、品牌、型号或画外来历。
5. 在计划合法字段中确定记录粒度、分组依据、应省略内容和复看位置。计划不是报告目录模板，也不创造服务端没有提供的记录编号或资产资源。

# Draft

利用正式 title、summary、sections/body/items/evidence 组织已观察内容，只写所选用途所需的信息。开篇简要说明整理对象、粒度与重要覆盖限制，不用评价性结论充当素材目录。

- 叙事片段按来源时间排列，写清此段发生什么、进入与离开时的相关状态及与相邻片段的关系。原片只是信息展示时，按其实际内容整理，不强行找人物冲突。
- 镜头记录说明画面范围、主要主体、可见动作与信息职责，以及经过核查的起止位置。若边界未能精确确认，正文明确候选或所见范围，evidence 只绑定可支持的原视频位置。不能用时间等分凑镜数，也不能把一个连续镜头的多个观察帧写成多个剪切。
- 场景记录说明可见地点特征、行动或信息推进及前后变化。未确认真实时空连续性时保留未知，不能把镜头换角度直接当新场景。
- 资产记录按可见同一性整理重复出现，说明识别依据、可见状态和位置；无法判定是否同一候选时分别描述或说明待核对，不为去重而强行合并。记录不能变成图片、提示词、生产资产或采购清单。
- 描述与解释分开，文字看不清就说无法确认，未核验声音不转录对白或编造声源。报告采用所选中文或英文；limitations 保留实际覆盖与分辨率等限制，字段保持正式契约。

# Review

独立核对记录的时间顺序、位置、分组、边界和去重依据。每条主要记录必须可回看；检查遗漏或重复的观察内容，但不能将稀疏取证宣称为完整逐帧目录。对剪切候选查相邻画面，对同一性归并查稳定可见特征，对叙事因果查前后行动。

概览图的 16 格按从左到右、从上到下对应工具返回的位置。若发现概览和单帧似乎矛盾，先核对格子位置，再用同一位置的单帧复看；疑似误读不能直接升级为已确认的来源冲突。无法复看时保留未确认，不用新的推测替换已有可核查事实。

删除与用途无关的高光、评分、优缺点和泛泛建议；不为让记录“完整”而补造未知字段。能确认的事实明确写出，尚不能确认的具体条件保持未知。整理是否帮助用户找到并理解原素材是首要标准，不要求每条写长篇术语解释；审校只返回本阶段要求的正式结构。
