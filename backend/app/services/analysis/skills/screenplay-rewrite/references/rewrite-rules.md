# 中英文改写规则

## 忠实边界

- 保留人物意图、行动、因果、时间关系、地点和已确立的世界设定；不得为“更顺”而补剧情。
- 舞台指示保持可拍摄、可观察；不要把动作改写成无法表演的抽象心理说明。
- 对源文歧义采用最少假设的表达，并在 change summary 说明必要的语言级处理。

## 语言策略

- `zh-CN → en-US`：避免逐字翻译中文语序；称谓与关系信息需自然呈现，但不擅自西化姓名或地点。
- `en-US → zh-CN`：使用自然简体中文对白，保留语气、权力关系和信息释放顺序。
- 同语言润色只修正清晰度、节奏、重复和不自然表达，不改变角色声音或文本事实。

## 一致性与覆盖

- glossary 的同一 source 只对应一个 canonical target；上下文需要不同译法时不得偷偷漂移，应在摘要说明。
- 相邻块只作为上下文，不能把相邻场景内容重复写入当前块。
- 合并前检查场景数、源场景 ID、part 连续性、源哈希和非空正文；任何缺失、重复或乱序都应使结果失败。

## 项目版本边界

- 术语表用于跨场景的语言一致性，不是资产清单；不因为出现一个角色、地点或道具名就生成新的生产对象。
- 语言改写可能改变字符长度，但不能改变源场景身份、场景顺序、对白归属、动作因果或可追踪的源哈希绑定。
- 如果源文存在结构歧义，只做最小语言处理；不要借改写机会补写剧情、修复连续性或替作者做主选决策。
