# 剪辑节奏量表

## 一、观察维度

逐镜记录以下可见维度，并留意贯穿全片的模式，而不只是单次事件。例如“每换一个步骤就硬切并轻推近”“画面文字总在动作完成后才出现”：

| 维度 | 看什么 |
|---|---|
| 画面类型与构图 | 人物、屏幕录制、空镜、文字卡；景别远近；主体在画面中的位置 |
| 切点节奏 | 切点落在哪里、密度如何变化；是否落在动作完成、视线转移或信息出现处 |
| 画面文字 | 出现和消失的时机、位置、字号，与主体动作是否竞争 |
| 镜内运动 | 推近、拉远、摇移、变速等强调手段出现在哪里，力度如何 |
| 插入与叠加 | 插入镜、贴纸、箭头、截图等叠加元素何时出现，是否打断主线 |
| 节奏曲线 | 全片是持续高密度，还是“快开场、慢中段、快收尾”，能量在哪里起伏 |

## 二、逐镜标签

标签写入 `visual_tags`，只用于检索，不进入报告正文：

- 停留：`pace:readable-hold`、`pace:underheld`、`pace:overheld`
- 切点：`cut:action`、`cut:reveal`、`cut:spatial`、`cut:beat`、`cut:unclear`
- 信息密度：`density:sparse`、`density:balanced`、`density:overload`
- 视觉连续：`motion:carry`、`motion:reset`、`attention:guided`、`attention:competing`
- 边界：`boundary:edit`、`boundary:continuous-beat`、`boundary:uncertain`

标签只在可见证据成立时使用；同一镜头可以同时是必要的长停留和高信息密度。

## 三、判断规则

1. 阅读文字、理解界面操作、识别空间或观察状态变化所需的停留有明确用途。
2. 画面没有新增动作、信息、构图或情绪状态时，长停留才可能构成拖延。
3. 快切若持续提供清晰的动作或空间承接，可以有效；切换频繁但注意力锚点不断重置时，才构成无目的快切。
4. 信息过载看同一时刻竞争的主体、文字、运动和界面变化，不用镜头数量替代判断。
5. 节奏建议先保护理解，再讨论速度；不把所有问题都归结为“剪短”。

## 四、字段写法

- 分镜 `narrative_function` 一句话说明这次停留或切换的用途。
- `recommended_extensions` 每条是完整句子：涉及的分镜（正文写“分镜 004”）、观察到的问题、修改动作和期望效果。例如：“分镜 009–011 连续三次展示同一个界面，没有新操作；合并为一次停留并在结束处保留完整画面，观众仍能读清按钮位置。”

## 五、交付自检

- 结论同时考虑停留、切点、信息密度和段落变化。
- 每条建议都能回到具体分镜，并说明修订后应改善的可读性或推进效果。
- 没有用音频、平台指标或固定行业阈值冒充当前成片的证据。
