# README visual assets

Hand-authored static SVGs for the Chinese and English repository homepages.
Edit text and geometry directly in the SVG files; no generator or runtime dependency is required.

- Palette follows the project neutral theme: `#fafafa`, `#f5f5f5`, `#e5e5e5`, `#737373`, `#171717`.
- The hero is a conceptual material/report diagram, not a product screenshot or acceptance evidence.
- The official logo and existing UI screenshots remain in their original locations.
- Preserve the `viewBox`, accessible title/description, and system font stack. Keep commands and capability details in Markdown.
- Check edits at 900px and 360px widths on light and dark page backgrounds.
