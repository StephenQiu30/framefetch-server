# AI 分析

本文规定分析任务的契约、执行、证据与安全边界。提供哪些 Skill、各自产出什么由 [PRD](../prd/README.md) 定义。

## 调用契约

| 接口 | 用途 |
| --- | --- |
| `GET /api/analysis-skills` | Skill 清单：`display_name`、`description`、`default_prompt`、`input_kinds`、`result_contract` |
| `POST /api/downloads/{download_id}/analyses` | 对视频创建分析 |
| `POST /api/documents/{document_id}/analyses` | 对剧本文档创建分析 |

- `AnalysisRequest` 包含 `skill_id`、`output_language`（`zh-CN` 或 `en-US`）与最多 4000 字的 `custom_prompt`。客户端表单的 Skill 选择、语言、可编辑默认提示词与“恢复默认”直接使用清单字段。
- 分析读取 owner 的完整持久化正文与真实制品，不以预览代替全文。
- Skill 的材料要求与结果类型必须与实际输入匹配：普通文章不要求剧本场景，文档分析不生成视频时长或媒体指标。

## 执行

- 任务模型为 AnalysisJob／Run／Step／Report。创建时同事务写入任务、配额与 Outbox，dispatcher 直接启动 Temporal 分析 Workflow（宿主 Task Queue `ff-skill`）；报告发布走 RabbitMQ。
- 来源与方法在创建时固定指纹。模型调用前登记持久步骤；回执未知的调用禁止自动重发。
- 取消、执行所有权丢失与迟到结果由 fence 拒绝；心跳失败时停止已失去所有权的执行。
- 模型通过已配置的 AI Provider 或宿主官方 CLI 登录调用，CLI 认证不挂载进容器。
- 分析与下载相互独立，AI 失败不改变下载成功状态。

## 工具与证据

- FFprobe、FFmpeg 取帧与时间、原文定位、引用与覆盖校验是内部工具，不单独建目录页或材料库。
- 工具没有任意网络或 shell 权限；外部操作有限额，取消时终止整个进程组。
- 画面分析标明实际采样范围，不声称理解了完整声音或运动。结论、依据、影响与建议相互对应。
- 模型输出必须通过严格 schema 校验；视频结果要求连续的分镜时间轴与 shot evidence。
- 文档整理保持原有事实、代码、链接、引用与表格；不以机械换行、字段包装或截取开头冒充完成。

## 结果与历史

- 结果按 `result_contract` 判别联合存储与渲染，历史记录按其真实类型读取，不转换为其他类型，不用当前方法补造过去的指纹。
- 个人处理记录中的分析类型为 `video_analysis`、`screenplay_analysis`、`skill_analysis` 与 `content_creation`；后两者对已有记录只读展示。
- 完整原文、Prompt、原始模型响应与凭据不进入普通日志或 Temporal History。
