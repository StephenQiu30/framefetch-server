# Web 体验

视觉与组件规则见 [design.md](../../../design.md)，前端目录与页面状态组件见 [PROJECT.md](../../../PROJECT.md#6-前端)。

## 数据与缓存

- 根布局挂载一次身份投影与 TanStack Query 缓存。查询键按 owner、资源与参数隔离；事件驱动定向更新，WebSocket 重连后用 HTTP 快照收敛。
- 后台刷新不清空已有数据；只有首次加载显示加载占位。
- 草稿按 owner 保存在会话内存，不写入 URL、共享存储或遥测。
- 切换账号或确认会话失效时，立即隐藏私有内容并清理缓存与在途请求。身份未知且网络异常时原地恢复，不伪造为匿名。

## 分析页面

- 视频与剧本文档详情页提供 Skill 选择、输出语言、可编辑默认提示词、恢复默认、执行状态、运行历史与报告阅读。
- 文章类材料通过文档分析表单与正式结果契约接入，不要求伪造剧本场景。
- 报告阅读器正确呈现代码、换行、表格与长 SHA；MD／DOCX 下载读取已保存结果。

## 公开页与 SEO

- 公开页只有匿名视图下的 `/` 与 `/guide/`，以及随构建产出的 `/self-hosting/`、`/about/` 等说明页；其他页面默认 `noindex`。
- `SITE_INDEXABLE` 默认 `false`，明确设为 `true` 才允许首页与指南被索引；`SITE_URL` 必须是无凭据的绝对地址；修改后需重建镜像。
- 匿名首屏无需 JS 即可阅读；`robots.txt` 屏蔽 `/api` 与 `/health`；结构化数据只包含真实内容，不含虚构评分或价格。
