# 接口契约

- **唯一链路**：路由与 Pydantic 模型 → `/openapi.json` → `@umijs/openapi` → `frontend/src/api/`。生成代码不手改。App 从同一 OpenAPI 按白名单冻结快照并生成 Dart 客户端；桌面端同步 Frontend 的生成结果。
- **统一响应**：Web 业务 JSON 为 `{code, message, data}`，成功 `code=ok`，保留真实 HTTP 状态。公开错误码由 `core/error_codes.py` 枚举，`api/errors.py` 唯一映射。204、文件流、Range、WebSocket、健康探针与指标遵循各自协议。
- **工作区文档**：`GET /api/workspace/documents` 与 `GET /api/workspace/document?path=` 公开读取 `workspace/content` 下的 `.md` 文档；`PUT /api/workspace/document?path=` 仅管理员可用，请求携带读取时的 `base_sha256`，不一致返回 `409 workspace_document_conflict`。接口只覆盖已有文档，不新建或删除文件。
- **原生认证**：`/api/app/v1/auth/*` 使用直接响应与 Bearer 契约，不套统一包装；修改须同步 `framefetch-app` 验收。
- **媒体内部接口**：`/internal/engine-catalog`、`/internal/inspect`、`/internal/download`、`/internal/tasks/{task_id}` 及其取消与制品资源。HMAC 绑定实际请求路径；调用方与 Runner 配套发布，不设别名。
- **解析结果**：解析与下载响应提供只读的 `execution_context`（[解析引擎](14-解析引擎.md#9-执行上下文)的十二字段）；失败包含 layer、stage、gate、结构化 evidence 与摘要。
