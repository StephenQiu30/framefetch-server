# 身份与会话

本文是帧取账户的登录会话。第三方平台的账号材料见[平台身份](15-平台身份.md)，两者严格分离。

- **Web 与桌面**：PostgreSQL 保存不透明会话；同源 HttpOnly Cookie 只持有随机凭据，库中保存摘要、空闲与绝对截止及撤销时间。普通请求不轮换 Cookie，WebSocket 心跳不续期。写操作校验精确 Origin／Referer，代理来源只取自受信 IP／CIDR。
- **原生 App**：短期 Access Token 只在 App 内存；Refresh Credential 可轮换、可撤销，存于系统安全存储；轮换后旧凭据不可重放。注册需邮箱验证码。
- **首位管理员**：未配置 SMTP 时，部署者在本机终端交互设置首位管理员密码，单事务锁定空 `users` 表；没有公网初始化端点或默认密码。
- **失效语义**：平台账号失效只影响对应平台的任务，不导致应用登出。只有服务端明确拒绝应用会话才进入重新登录；连接异常不等于未登录。
