# 视频去水印需求

帧取提供内置自动去水印能力，不要求用户配置位置、时间段或算法。技术规则见[视频去水印设计](../design/16-视频去水印.md)，实际验证与未完成项见[执行计划](../plan/PLAN-视频去水印.md)。

## 1. 用户流程与验收

- 首页新增「视频去水印」Tab：选择本地 MP4，点击「上传并去水印」，进入任务详情查看状态与保存文件。复用已有分片上传，不增加专门编辑页。
- 所有 URL 视频下载默认执行无水印源优选，原片验证完成后自动进入水印识别与处理，不增加开关、模式或额外确认。
- 原有「本地视频」入口仍用于普通导入；只有专用去水印 Tab 的上传自动处理。
- 下载详情不出现框选画布、坐标、时间段、算法或参数表单。仅显示自动处理状态，以及原片和处理版的保存入口；失败可重试处理，不重新下载平台视频。
- 原片始终保留。未检出可处理的水印时直接使用原片；失败不伪装成去水印成功，也不影响原片保存。

无水印源优选仍需满足用户选择的画质与原有内容范围。来源声明无水印不保证没有作者烧录标记。局部修补可能改变遮挡处细节，处理完成不代表所有水印都能无痕消除。

当前执行器支持 180 秒内、1080p 像素数量以内的普通 8-bit SDR 视频及 AAC 音轨；超出范围保留原片并显示处理未完成。识别覆盖带有已知品牌文字的边角标记；纯图形、中心水印、低透明度及复杂移动标记的覆盖仍需扩充真实样本验证。

## 2. 市场与使用场景

目标用户是管理自有或获授权视频素材的个人创作者、研究者与视频资料整理者。核心任务是粘贴链接后得到可用素材，减少另开工具、重新上传、手动导出和重新导入的步骤。

相关市场有两个相邻类别：无水印链接下载器、视频水印与对象修复工具。前者突出免费和少操作，后者突出 AI、预览及高级处理额度。下表是五个主要替代产品，不把编辑工具误列为与帧取整体定位相同的直接竞品。

本轮没有可核实的去水印细分市场规模、增长率、份额、融资、活跃用户或留存数据，不以宽泛的视频编辑市场数字代替。机会判断来自公开产品能力与项目使用场景，不等于经过用户访谈或实际效果对照验证的市场结论。

## 4. 产品边界

按单人自托管工具取舍，识别与修补默认在本机执行，不调用公共解析站、不默认上传云端视频、不新增商业化或复杂任务配置。算法依赖和执行细节由内置服务管理，不进入用户操作流程。

原片与处理版分别保存；AI 分析继续读取原片，避免修补画面成为原始内容证据。本功能不扩展为视频剪辑器或人工对象编辑器。
