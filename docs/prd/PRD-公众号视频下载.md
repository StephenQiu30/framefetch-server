# 公众号视频下载

## 用户任务与范围

用户粘贴公开公众号文章链接，选择其中一个视频，确认下载规格并保存文件。原生视频支持微信官方 `mpvideo.qpic.cn` 的非加密 MP4；腾讯视频外链沿用 `personal_full`，含有效官方分享链接的视频号沿用 `official_share`。外链不会获得比对应平台更宽的内容范围。

不以文章正文、封面、候选发现或元数据成功代替视频交付。文章归档、公众号历史批量抓取、DRM 解密和受限内容不在范围内。

## 功能与验收

- 文章包含多个视频时逐项展示，由用户显式选择，不自动下载第一项。
- 选择提交到唯一持久解析意图，沿用取消、期限、刷新、幂等与配额规则；客户端只提交 owner 范围的 discovery 与 item 引用。
- 原生视频的媒体身份、档位和完整时长来自当前官方文章元数据；签名直链只在 Runner 操作内使用，下载时重新取得并核对作品身份。
- 用户可以确认格式并下载，通过正式 API 取回 Artifact。必须核对实际大小、SHA-256、音视频轨时长与规格并全片解码。
- 删除、禁止访问、挑战、来源歧义、未知媒体域、加密或没有可用视频时明确失败，不伪造可下载规格。
- 原生视频至少两部不同作品通过真实完整文件验证。Web 浏览器操作、桌面同步和 App 契约各自记录验证范围；未执行的检查不声明通过。
