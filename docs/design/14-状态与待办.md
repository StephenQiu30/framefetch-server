# 状态与待办

## 当前导航

解析引擎按[设计 17](17-解析引擎重建.md)的 R0 → R1 → R2 → R3 → R4 → R5 → R6 推进；阶段勾选与验收证据只在其第 8 节维护。

| 领域 | 状态与证据边界 |
| --- | --- |
| 解析意图、历史、Web 认证、配额与操作日志 | 保留既有业务链路；R0 收缩为单 resolve Activity |
| 媒体执行 | R0 仅匿名 L1，保留 SSRF、代理、制品校验与 RabbitMQ 下载 lease/heartbeat；真实公开样本须重新验收 |
| 治理与旧会话链 | R0 删除 canary、cooldown、发行身份、broker、密封与解析管控账本；声明能力不等于已验证下载 |
| 身份与浏览器阶梯 | R3、R4 目标尚待实施；保留 browser_runtime 与 Chrome Cookie 纯读取模块 |
| AI 分析与导入 | 保留现有 SkillWorkflow、步骤日志、报告发布与第三方 Web Provider；真实模型及目标机器验收独立维护 |
| 腾讯／优酷账号内容、微信视频号 | 不以旧接入或 Cookie 可读声称完整文件通过，按 R4–R6重新验收 |
| Edge Agent、授权 Connector、创作与发布 | 后续需求；不在 R0 实施 |

R0 的确定性检查、App 原仓库变更、双方互审与哔哩哔哩文件验收须全部完成才可勾选。权限或运行环境阻断时记录原始错误，保留未通过状态。
