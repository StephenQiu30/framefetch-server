# 准入、配额与容量

- Redis 限流：登录、注册、验证码同时按邮箱摘要与真实客户端 IP；已登录高成本操作按账户与操作；`RATE_LIMIT_POLICIES` 可局部覆盖，未知操作拒绝启动。
- PostgreSQL 持久配额在资源创建事务内检查（同事务写资源、分析 run 与 Outbox），只取账户事务锁，重放判断先于扣减：每账户活跃任务 5、24 小时任务数 50、24 小时处理字节 100 GiB、保留存储 100 GiB、24 小时分析尝试预算 60（`QUOTA_LIMITS` 可局部覆盖）。管理员身份从会话中的数据库角色派生，不受账户级配额约束；可为普通账户设置豁免或单项覆盖。
- 全局执行容量由 RabbitMQ 队列、消费者 `prefetch` 与有界 Worker 池控制：容量不足时任务保持 `queued`，不返回 503。
- 可信代理由 `TRUSTED_PROXY_CIDRS` 声明，API 自行解析转发链，不信任客户端传入的地址。
