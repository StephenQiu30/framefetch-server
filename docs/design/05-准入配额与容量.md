# 准入、配额与容量

## 限流

Redis 计数。登录、注册、验证码同时按邮箱摘要与真实客户端 IP 限制；已登录的高成本操作按账户与操作限制。`RATE_LIMIT_POLICIES` 可局部覆盖，未知操作名拒绝启动。

## 持久配额

在资源创建事务内检查，与资源、分析 run、Outbox 同事务写入；只取账户事务锁，重放判断先于扣减。

| 配额 | 默认值 |
| --- | --- |
| 活跃任务 | 5 |
| 24 小时任务数 | 50 |
| 24 小时处理字节 | 100 GiB |
| 保留存储 | 100 GiB |
| 24 小时分析尝试 | 60 |

`QUOTA_LIMITS` 可局部覆盖。管理员角色从会话中的数据库角色派生，不受账户级配额约束；可为普通账户设置豁免或单项覆盖。

## 执行容量

由 RabbitMQ 队列、消费者 `prefetch`、Temporal Task Queue 并发与有界 Worker 池控制。容量不足时任务保持 `queued`，不返回 503。

## 可信代理

由 `TRUSTED_PROXY_CIDRS` 声明，API 自行解析转发链，不信任客户端传入的地址。Web 与工作区站点的固定代理地址由 `TRUSTED_WEB_PROXY_IPS` 声明，用于还原浏览器来源与客户端地址。
