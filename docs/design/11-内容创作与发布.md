# 内容交付与导出

产品格式与任务见 [PRD](../prd/PRD-内容创作Skill体系.md)，验证事实见 [PLAN](../plan/PLAN-内容创作Skill体系.md)。

导出只接受owner的已确认revision_id，不重新推理。第一次成功的文件及元数据保存到creation_exports，唯一约束为revision／format；后续直接返回同一字节及SHA。新人工版本另有新文件，原件和旧确认版不覆盖。文件失败保留结果，单独重试导出。

MD／DOCX保持正文结构；受限HTML本地预览禁脚本、危险URL与远程资源。ZIP包含实际资源、可编辑源与manifest，不分发不存在的图片。原图仅来自用户提交的真实PNG／JPEG／WebP与权利声明。卡图用明确本地中文字体进行换行、缺字、页数和溢出检查，真实PNG输出与文字整理分开。Docker字体由fonts-noto-cjk包提供，保留包版权许可，不拷贝宿主字体。

字幕导出在固定真实视频时长内验证cue并保留合法重叠。镜头CSV来自保存的实际候选；对照／连续性CSV来自已保存分析findings与引用序号。所有格式≤64MiB。HTTP返回private/no-store、nosniff和附件文件名；HTML附CSP sandbox。普通用户不能凭其他owner的task／revision取得文件。

本地HTML不代表公众号编辑器已接受；图卡不是已发布笔记。项目不登录账号、不保存外部草稿、不自动发布。目标编辑器、App真机与真实安装包需要各自验收证据。
