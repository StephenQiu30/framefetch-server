# 内容交付与导出

本页仅记录尚未清退的内容交付边界，不再定义通用文字创作、配图、渠道包、baoyu 或公众号连接器的产品路线图。新的影视任务、可编辑产物和格式选择统一见[影视 Skill PRD](../prd/PRD-影视Skill体系.md)。新能力尚未实施，本轮没有改变运行代码或创建外部账号草稿。

## 现存导出边界

现存运行文档记录生成结果阅读、来源回查以及 Markdown／DOCX 导出。既有生成正文由导出文件继续编辑；新 PRD 的站内字幕、镜头注释和修订清单校订属于后续需求，不能据此宣称已有编辑接口。

- 结果与导出状态分别记录；分析正文已可读、文件导出失败时只恢复导出，不重新调用模型。
- 导出绑定确定的结果和材料版本，已有文件不因生成新结果而被覆盖；原件和历史报告按保留规则处理。
- Markdown／DOCX 保持完整正文、合理层级与来源回查，不能夹带 Prompt、工具日志、私有凭据或伪造署名。
- 私有制品通过授权访问；导出成功不等于公开发布或账号草稿写入成功。

## 新目标的唯一来源

新任务将按用途增加 CSV、SRT／VTT、TXT 和可编辑版本，具体范围、输入条件和验收只由 PRD 维护。旧配图、封面、资产包、渠道包与公众号草稿方案及其排期、接口和验收要求已移除；不作为后续必须实现的承诺。

运行中的旧内容入口、渲染器和导出依赖是否仍有职责，在实施阶段按[旧 Skill 清退要求](../prd/PRD-影视Skill体系.md#82-旧代码清退要求)审计。历史文件保留与可取回分别验收，不为保留文件建立永久旧任务兼容层。
