# 报告导出

- 接口：`GET /api/analyses/{id}/report.md` 与 `GET /api/analyses/{id}/report.docx`。
- 两种文件读取同一份已保存、已校验的正式结果，不重新推理，不增加母稿、渠道包或人工版本确认。
- 取回时校验 owner 与任务状态；返回的是可直接打开的真实文件字节。
- 导出失败不改变分析的成功状态，可单独重做。

## 内容要求

- 报告包含实质正文，以及可理解的依据、覆盖范围与限制。依据不能只写内部编号。
- 视频报告引用实际的源时间与帧；文档报告引用准确原文，并保持原有事实、代码、链接、引用与表格。
- 原件 SHA、正文 SHA 与方法 SHA 含义不同，分别标注。历史记录未保存的元数据明确标为缺失，不从当前目录伪补。

## 客户端

三端沿用同一接口：Web 浏览器下载，桌面端使用系统保存对话框，App 使用系统文件保存与分享。不提供 HTML 编辑、剪辑或发布流程。

## 原生产物接入约定

[接入 PRD](../prd/PRD-影视Skill接入.md)要求的 JSON／HTML／关键帧／联系表／配图尚待实现。它们保存到私有对象存储，manifest 绑定 owner、任务、来源范围、方法及结果版本，记录类型、字节数和 SHA-256；普通 API 仅返回 metadata，不内联大文件。取回沿用 owner 与版本校验，导出不调用模型，部分或损坏产物不得发布。

HTML 预览使用无同源权限的 sandbox iframe，按冻结的内容策略限制网络与脚本；主应用凭据不传入。交互拉片只能经专用受控消息协议请求跳转，父页面重新验证任务、来源和时间范围；禁止通用脚本或请求桥。公众号 HTML 只读预览／复制／导出，真实微信草稿另验收。App 使用原生正文、镜头表和图片，HTML 作为系统文件交接，不引入 WebView。
