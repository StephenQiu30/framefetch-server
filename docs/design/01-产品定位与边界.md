# 产品定位与边界

帧取是部署者自用的个人视频工作站，不作为互联网服务运营。Web、Flutter App（`video-app`）与桌面端（`video-electron`）共用同一后端。

设计优先级：可靠启动、任务可恢复、配置与凭据来源清晰、日常维护少。不为多租户、高可用集群或未来扩展预留空转机制；结构调整以完整使用流程与故障恢复验证为依据。

## 做什么

- 视频链接：来源发现、解析、格式选择、异步下载与制品校验。平台范围与解析规则见[解析引擎](14-解析引擎.md)。
- 导入本地 MP4 与剧本文档（DOCX、可提取文字的 PDF、TXT、Markdown、Fountain）。
- 对已有视频与文档调用内置 Skill 分析，阅读并导出报告；Skill 范围由 [PRD](../prd/README.md) 定义。
- 管理：用户、文件、平台目录、AI 服务、使用统计与系统操作日志。

## 不做什么

- 不解密 DRM 或加密媒体，不取得内容密钥；内容范围只按 `public`、`personal_full`、`official_share` 声明执行。
- 不自动化账号密码、验证码或 2FA；不使用公共解析站、公共代理或 MITM。
- 不开放任意 yt-dlp／gallery-dl 参数、输出模板、shell 或文件路径；不接受用户上传的自定义 Skill。
- 普通业务请求不携带平台 Cookie；平台身份只经[平台身份](15-平台身份.md)的受控通道取得。
- 不提供直播录制、无限播放列表、频道归档、OCR、图片型 PDF、批量文件任务、在线协作编辑、剪辑、图卡制作或账号发布。

## 判定原则

URL 已登记、提取器存在、元数据成功、完整文件交付、AI 分析成功是五个相互独立的状态，任何一个都不能推出另一个。
