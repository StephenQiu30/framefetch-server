# 产品定位与边界

帧取是开源、自托管的个人视频工作站，面向一名部署者的日常使用：解析视频链接、选择格式、异步下载并交付授权制品，导入本地 MP4 与剧本文档，并对视频与剧本做结构化 AI 分析和报告导出。Web 与独立的 Flutter App（`video-app`）共用同一后端。

设计优先级是可靠启动、任务可恢复、配置与凭据来源清晰、减少日常维护。已有多用户、队列和容器结构是当前实现，不是必须保留的产品要求；重构以完整使用流程和故障恢复验证为依据，不为多租户、高可用集群或未来扩展预留空转机制。

**做什么**

- 公开或部署者有权访问的视频链接：来源发现、解析、格式选择、下载、制品校验。
- 本地 MP4 与剧本文档（DOCX、可提取文字的 PDF、TXT、Markdown、Fountain）导入。
- 视频视觉分析（分镜、高光、资产）、视频转文章、剧本分析与改写、Markdown／DOCX 报告。
- 管理端：用户、文件、平台目录、AI 服务、下载分析、系统操作日志、平台会话状态。

**不做什么**

- 不绕过 DRM、会员／付费权益、私密内容或地域限制；不做账号密码、验证码、2FA 自动化；不使用公共解析站、公共代理或 MITM。
- 不开放任意 yt-dlp／gallery-dl 参数、输出模板、Shell 或文件路径；不接受用户上传自定义 Skill。
- 不提供直播录制、无限播放列表、频道归档、OCR、图片型 PDF、批量文件任务、在线协作编辑。
- 普通业务请求不携带原始平台 Cookie；凭据接入通过独立受控通道完成。当前接入方式见[平台会话](08-平台会话.md)，不将某种浏览器接入技术固化为产品要求。

**判定原则**：URL 已登记、extractor 存在、metadata 成功、整文件下载成功、AI 分析成功是五个相互独立的状态，任何一个都不能推断另一个。
