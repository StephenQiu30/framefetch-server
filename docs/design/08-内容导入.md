# 内容导入

## 本地视频

`browser_import` 流程：创建受限上传会话 → 客户端分片直传预签名 URL（校验分片数、顺序、过期与 ETag，Content-Length 精确绑定）→ 文件进入 MinIO quarantine → Import Worker 复验容器、编码与时长 → 晋升为标准视频 Artifact。之后复用下载详情、AI 分析、报告与实时状态。

Web 浏览器经同源 `/storage-upload` 转发到 MinIO 预签名地址，只接受既有公网端点的 AWS4 预签名地址；原生 App 直传。

## 剧本文档

独立的 `documents` 聚合，保存原文件与规范化剧本文本（场景 ID、人物与对白结构、质量提示），单文件上限 50 MB（部署配置可调）。文档不伪造下载 inspection。

## 保存期限

- 上传会话、quarantine 与分片是临时状态，必须过期。
- 视频、剧本原件、规范化文本与报告持久保存，没有业务 TTL，只能被用户删除或由管理员显式清理。

## 删除

- **用户删除**：用户可删除自己的下载、制品、本地上传源与剧本文档。活动任务先取消；存在活动分析锁时返回冲突，不做部分删除。他人资源一律返回不存在。
- **文件管理**：管理员在 `/admin/files` 分页查看未清理的逻辑资源（视频、剧本、报告），不暴露 bucket、key 或签名 URL。列表按所属任务或文档关联当前用户名展示上传人，无法关联时显示“未知上传人”，不另存归属字段。
- **批量清理**：`POST /api/admin/files/cleanup` 按天数（1–3650）永久删除；被分析任务锁定的资源跳过；存储删除失败不标记已删除，可重试。
