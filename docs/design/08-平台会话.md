# 平台会话（宿主固定 Chrome Profile）

本页规定平台会话来源与传递边界；自动解析、冷启动下载、实施阶段及真实验收统一以[设计 17](17-通用解析架构与实施计划.md)为唯一计划。帧取是单人自部署服务，复用部署者已经登录的 Chrome；产品中不要求安装扩展、连接 Native Messaging、打开平台登录窗口或点击继续。技术链路与真实平台可用性分别验证。

## 来源与传递

```text
macOS 宿主固定 Chrome Profile
           ↓ yt-dlp 官方读取能力（已有系统权限、禁止 Keychain 交互）
        source_app
           ↓ 直接密封给 Runner
session-runner ← session-broker
```

- 宿主来源与 Chrome 属于同一 macOS 用户。`SITE_SESSION_CHROME_PROFILE` 固定已登录 Profile 的绝对路径；不扫描多个账号，不依据最近访问时间自动换 Profile。容器不挂载宿主 Profile 或 Keychain。
- Cookie 读取使用项目锁定的 yt-dlp 官方实现。读取所需的数据库临时快照在宿主读取期间使用并清理；不复制完整 Profile，不建立持久 Cookie 库或材料回写机制。
- Keychain 只允许使用已有非交互权限。权限拒绝、数据库不可读或读取超时均明确失败，不提示用户授权、不重启或改写 Chrome、不绕过操作系统控制。服务重启后的首次任务无需先打开 Chrome 标签页；此前提仍需真实冷启动验收。
- 来源按任务请求读取 Registry 批准站点，并检查 Cookie 域、字段、有效期与必要材料。未知站点拒绝，过期及外域材料不发送。来源不运行账户保活、平台预热或周期材料扫描。
- 会话代由固定 Profile、站点、认证材料及稳定来源密钥的 HMAC 摘要派生；同材料下来源进程重启不改变会话代。已声明必要 Cookie 集合的站点只绑定该集合；未声明集合时保守绑定该站点过滤后的材料，其他 Cookie 轮换也可能使旧上下文失效。Profile、密钥或绑定材料变化使旧上下文失效。会话代不是已经验证的平台账号 ID。
- source_app 将材料直接密封给 Runner 临时公钥，绑定任务、站点、会话代与截止时间；保留现有 Source API、签名 RPC 与短期租约。Broker 只转发，不保存材料、解密或建立第二套任务状态。
- Runner 在单次操作的 tmpfs 私有文件中使用材料，完成、失败、取消后清理。材料不进入业务数据库、队列、Temporal、普通 API 响应、日志或 AI。
- Cookie 读取不具备任意页面请求头生成能力。视频号元宝等需要页面特定认证头的路线，若当前来源不能取得所需材料，应明确失败；不能由 Cookie 可读推断这些平台已经支持无感下载。

## 解析与下载

访问方式由 Registry 的 Profile 声明。固定公开线路不读取账号材料；公开账号线路保持声明的匿名与批准会话策略，个人权益使用已确认线路。不因限流、网络错误、模糊 Cookie 提示、私有内容或 PO Token 故障临时换账号。选定策略和执行上下文冻结后，下载按同一来源代校验，并在开工前重新解析原视频与语义规格。

来源未就绪或不可读与平台明确拒绝会话必须分别返回错误。自动准备和恢复沿原任务、原截止时间和共用预算执行，不新增平台登录/继续接口或 24 小时人工等待。重复取得相同不可用上下文不能消耗无限重试或生成新任务。

Cookie 复用只提供登录材料。YouTube 的配套 JavaScript/EJS 与 PO Token、抖音的网页初始化、出口、User-Agent、Cookie 与媒体 headers 仍由对应平台执行路径承担。解析与下载的上下文一致性必须验证，metadata 成功不等于完整媒体成功。限流保留真实原因与既有冷却，不改写为需要重新登录，不保证有 Cookie 就能通过所有平台请求。

## 安装与验证边界

命令、固定 Profile 配置和宿主启动说明见[根 README](../../README.md)。`source_cli` 只提供 `serve`、`install`、`uninstall`、`check`；安装仅管理宿主来源服务，不安装扩展或打开浏览器。`check` 是按需材料可读性诊断，不作为每次任务的操作前置。

健康接口只证明来源服务就绪，`source_ready` 只证明来源能提供所需材料；传递、密封、取消和模拟材料测试只证明技术链路。完整媒体、设备保存、重复下载和同材料重启需各自取得真实证据。没有完整文件与冷启动证据时，不宣称所有平台无感解析已经通过。
