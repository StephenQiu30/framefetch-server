# 平台身份

身份层的唯一规格为[设计 17 第 3.4 节](17-解析引擎重建.md#34-身份层)，实施与验收在其 R4 中维护。

R0 删除旧 broker、密封、会话代、短期租约与来源服务命令；Runner 仅使用匿名 L1。保留宿主固定 Chrome Profile 的纯 Cookie 读取模块，不启用 cookie-source，也不声明登录平台可用。

R4 的宿主启动方式、钥匙串无图形交互验证、身份传递与私有 tmpfs 清理由设计 17 第 3.4 节统一定义；使用时机由 Registry identity 决定。安装命令在实现并验收后写入 README。

Cookie 可读和进程健康不能证明完整文件交付；真实身份层样本须按设计 17 验收。
