# 平台会话（容器自持）

在线解析要求已验证的站点会话（账号平台）；一次导入后由容器保活，不承诺永久免登录。

## 拓扑

- `session-runner` → 单任务租约 → `session-broker`；broker 是解密密钥（`SITE_SESSION_ENCRYPTION_KEY`）的唯一持有者，通过签名 RPC 调用 `session-browser`，不访问外网。
- `session-browser` 为每站点维护独立持久 Chromium Profile，无数据库、密钥、队列权限。
- broker 与 Runner 共用 Redis 站点锁（同站点单并发）；浏览器、Runner、POT 使用受控出口（`RUNNER_PROVIDER_EGRESS_PROXIES`，默认指向 `egress-proxy`）。
- 默认单 broker，尚不支持横向扩容 broker；Runner 可共享站点锁扩容。

## 状态与调度

`seeded → verifying → ready`；临时故障 `degraded`；明确登出、解密失败或连续认证失败 `reseed_required`；撤销 `revoked`。

- 普通检查 30 分钟 + 0～5 分钟正向抖动；临时故障 60 秒起指数退避到 30 分钟，429 至少 5 分钟；退避写库，重启不绕过冷却。
- 网络、浏览器不可达、403／bot challenge 不计认证失败；仅明确 `credential_expired／credential_rejected` 连续 3 次或认证降级 24 小时进入 `reseed_required`。
- broker 启动不信任持久 `ready`，立即校验；浏览器公钥是运行期身份，变化即清空运行期准入。维护开始即阻止新租约，等待站点锁释放。
- 登录探针集中于 `session/login_probes.py`，仅返回布尔值；未知或未初始化返回临时不可用而非登出。

## 导入与租约

- 首次导入：macOS `./start` 应用当前 SQL、启动业务 Compose、执行有界自动接入并安装 LaunchAgent，等待 broker 真实运行期准入，未就绪返回非零。仅在缺失或 `reseed_required` 时读取宿主 Chrome；单一已登录 Profile 自动绑定，多个候选需指定一次；来源指纹以 HMAC 随 `seed_revision` 原子保存，同一被拒材料不重复导入。Linux 纯容器部署只恢复已有会话。
- 任务租约：Runner 每次操作生成独立 ID 与密钥；broker 返回绑定操作、站点、修订与到期时间的封装 Cookie，Runner 仅写 tmpfs（`0600`），结束即删。Cookie 不进入 API、RabbitMQ、日志、响应或 AI Worker。
- Cookie 轮换：Runner 变更的 Cookie 经 allowlist 校验后封装回 broker（最多 1024 个待返回，窗口 7500 秒），broker 用浏览器验证新 jar，只有 verified 才条件发布；旧修订不能覆盖新导入或复活墓碑。
- 撤销：站点回到公开路线，浏览器 Profile 删除；平台侧撤销由部署者完成。`/admin/provider-runtime` 返回脱敏状态（`no-store`），后台前台轮询 15 秒。
- 设计边界：Cookie 存在、HTTP 200、进程健康都不等于媒体可用；平台 challenge 仍可使有效登录态无法解析。
