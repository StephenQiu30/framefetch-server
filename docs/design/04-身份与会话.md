# 身份与会话

- **Web**：PostgreSQL 不透明 Web Session；同源 HttpOnly Cookie 只持有随机凭据，库中保存摘要、空闲／绝对截止与撤销时间；普通请求不轮换 Cookie，WebSocket 心跳不续期；写操作校验精确 Origin／Referer，代理来源仅取自受信 IP／CIDR。
- **原生 App**：短期 Access Token（App 内存）+ 可轮换、可撤销的 Refresh Credential（系统安全存储），Refresh Rotation，旧凭据不可重放；注册需邮箱验证码。
- **首位管理员**：默认未配置 SMTP 时，部署者在本机终端交互设置首管理员密码，单事务锁定空 `users` 表；无公网初始化端点、无默认密码。
- 应用登录与第三方平台会话严格分离：第三方失效只影响对应平台与任务，不导致应用登出；服务端明确拒绝应用会话才进入重新登录，连接异常不等于未登录。
