# 内容导入

- **本地 MP4**：`browser_import`——创建受限上传会话，客户端分片直传预签名 URL（校验分片数、顺序、过期与 ETag，Content-Length 精确绑定），文件进入 MinIO quarantine，Import Worker 复验容器／编码／时长后晋升为标准视频 Artifact，之后复用下载详情、AI 分析、报告与 WebSocket。
- **剧本文档**：独立 `documents` 聚合，保存原文件与规范化剧本文本（场景 ID、人物／对白基础结构、质量提示），最大 50 MB；不伪造下载 inspection。
- 上传会话、quarantine、分片属于临时状态，必须过期；成功后的视频、剧本原件、规范化文本与报告持久保存，无业务 TTL，只能由管理员显式清理。
- **文件管理**：管理员 `/admin/files` 分页查看未清理的逻辑资源（视频／剧本／报告，不暴露 bucket、key 与签名 URL）；`POST /api/admin/files/cleanup`（1–3650 天）永久删除，被分析任务锁定的资源跳过，存储删除失败不标记已删除，可重试。
- 文件列表展示上传人，按视频下载／导入任务、剧本文档或报告分析任务的所属账号关联当前用户名；无法关联账号时显示“未知上传人”，仍保留文件记录。桌面分列展示，窄屏放入文件摘要，不为此保存另一份账号归属字段。
- **用户删除**：用户可删除自己的下载、制品、本地上传源与剧本文档；活动任务先取消，存在活动分析锁返回冲突，不部分删除；其他用户资源统一返回不存在。
- Web 浏览器上传通过同源 `/storage-upload` 转发到 MinIO 预签名地址（仅接受既有公网端点的 AWS4 预签名地址，不允许任意目标）；原生 App 直传。
