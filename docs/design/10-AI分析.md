# 内容 Skill 分析执行

产品任务与边界由 [PRD](../prd/PRD-内容创作Skill体系.md) 定义，实施证据由 [PLAN](../plan/PLAN-内容创作Skill体系.md) 维护。

## 事实与接口

唯一新接口为 /api/creation：作品、材料／材料版本、任务／任务版本、确认、取消、受控重试及版本文件导出。OpenAPI 生成 Web／Electron／原生 App 契约。旧分析创建、重试、目录和导入器已清退；保留 owner 校验的历史结果、来源、版本、报告、取消与删除 reader，不再执行旧 Skill。

PostgreSQL 保存 creation_projects、creation_materials、creation_tasks、creation_revisions、creation_exports。材料／结果正文和结构数据一起计算 SHA。每次保存追加版本、要求 expected_revision_id；确认是显式人工动作，模型发布只得到 awaiting_confirmation。原件 binary_data 与初始提取元数据独立保存；源文档取回校验其原 SHA，人工编辑不能改原件字段。

确认结果复用材料必须绑定 source_revision_id，属于同一 owner且已确认；自由正文或data不一致拒绝。上游产生新版本后，依赖任务标 stale，原材料正文和已生成文件不变，不自动推理。

## 编排与模型

API 事务原子保存任务与 creation.requested Outbox，含task_id、attempt和幂等摘要，不含正文／凭据。dispatcher直接启动 CreationWorkflow，ID为 creation/{task_id}/{attempt}，Task Queue复用 ff-skill。Activity只尝试一次；丢失或失败后 reconcile只收敛状态，不再调用模型。宿主Worker同时维护在线心跳，不新增基础容器。

claim固定方法SHA、材料版本与期限。调用前持久占用调用预算，已知回执结算；未知回执占用保留，取消与Worker失联不能自动重发。手动已知失败重试沿用累计次数；未知结果禁止盲重试。Token数仅预留，适配器未提供审计金额／Token，不能承诺金额封顶。

现有管理员Provider加密配置与宿主CLI登录复用；密钥只在Worker内存解密。每次任务独立私有工作区，Codex App Server使用strict schema与localImage实际PNG；不支持图像的适配器在调用前拒绝视觉任务。供应商是否实际支持图像与结构化输出需真实验证，不能按名称推断。

## 依据与工具

Drama确定性建立章节／场景完整索引，Unicode位置与单元SHA固定，模型须逐单元返回section；完整性只属于结构验证。事实引用检查原文范围、精确引文、材料SHA；模型语义支持仍需人工核查。

本地媒体必须来自owner已验证制品。FFprobe校正源时间与实际视频范围，FFmpeg检测切点并抽取真实PNG。模型每任务最多12帧，观察只覆盖所提供帧；不声称听音、运动或全片已检查。结果持久保存帧／预览双SHA、材料版本、源时间与有界PNG预览，工作区删除后仍能回查。镜头候选与非对白声音笔记由用户核查。

文档提取限制实际大小、压缩条目、页面与正文，支持UTF-8／DOCX／可提取PDF，无OCR。字幕只处理用户SRT／VTT，执行及导出均用固定视频真实时长，不接受用户伪造duration解除边界。

完整Prompt、原始响应、作品及凭据不进普通日志或Temporal History。材料内指令不能扩大工具权限。生成、导出、确认和专业质量是不同状态，不能把schema通过记为事实正确。
