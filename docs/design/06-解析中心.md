# 解析中心与持久意图

解析不在 HTTP 内同步等待，而是以持久的 `download_intent` 为唯一入口：

- **接单**：输入规范化（`public_input` 从分享文案提取恰好一个 HTTP(S) URL，多个 URL 拒绝）、加密存储、owner 配额与 Outbox 在同一事务提交，返回 `202`。`(owner, idempotency_key)` 唯一；重放只返回原意图，不重置 180 秒截止与预算。
- **状态机**：`queued → preparing → resolving → ready → handed_off`；可恢复故障进入 `retry_wait`；需要授权动作进入 `action_required`；终态 `cancelled / expired / failed`。终态 CAS，迟到结果不能覆盖；所有写入检查 lease、fencing token 与 state version。最多 3 次尝试，等待用户选择格式不消耗执行预算。
- **执行**：下载 Worker 用两个独立解析消费槽与恢复循环执行（队列 `video.download-intent`，不占下载槽）；`FOR UPDATE SKIP LOCKED` 有界扫描到期重试、过期租约与丢失投递；Runner 在断连时传播取消到进程组终止与工作目录清理。
- **结果**：inspection、formats 与 `ready` 在同一事务提交。格式推荐顺序是后端规则（优先保留音轨，再按分辨率、容器、编码、帧率稳定排序），投影与探针一致。仅 `access_decision=downloadable` 可确认下载；确认后由既有 `POST /api/downloads` 交接，同一 inspection 唯一交接。
- **过期与刷新**：inspection 过期后 `refresh` 保留原意图，重解析必须核对平台内容标识与媒体类别，格式变化须用户重新确认，不自动下载；不复用失效直链。
- **来源发现**：微信公众号文章先做多候选发现，用户显式选择后再解析。
- **恢复**：客户端响应丢失时以同一幂等键只读查询（不重发 POST）；账号绑定的历史列表（游标分页，单页最多 50）用于跨设备找回，不返回原始输入或幂等键。
- **个人处理记录**：`GET /api/download-intents/history/records` 对解析意图、视频 AI、剧本基础解析、剧本 AI 做 owner 范围联合查询（排序 `created_at DESC, id DESC, record_type DESC`，过滤先于 LIMIT，无 COUNT），不新增万能任务表；来源与结果可用性分别标注 `available/unavailable/unknown/not_applicable`；详情与写操作重新校验权限。
- **管理员操作日志**：`operation_logs` 记录写请求生命周期（路由执行前 started、完成后一次结果写入）与由 SQL 触发器在业务事务中写入的任务状态事件；不持有用户外键、不记录完整 payload；入口 `/admin/operation-logs`。个人记录入口 `/history/activity`。
