# 可靠性与运行

- **故障隔离**：API readiness 只检查 PostgreSQL 结构、MinIO、RabbitMQ、Redis，不探测 Runner；Provider 故障由稳定错误与探针表达；worker 不等待所有 Provider；其中每个后台组件独立监督，单个组件失败按退避重启，不影响其他组件。
- **停止与恢复**：解析由 Temporal 持久调度，Activity 心跳约 5 秒、失联检测 30 秒，独立的 generation／fence 拒绝迟到提交，取消通过同事务 Outbox 传递。Skill 分析同样由 Temporal 调度，替补 Activity 以新的执行者 fence 接管运行，取消沿用数据库标记并由心跳感知；步骤日志保证中断的模型调用不被自动重发。下载仍为 60 秒有限排空和 PostgreSQL 租约恢复，容器停止宽限 90 秒；下载与导入按职责长期保留 RabbitMQ 的 sweeper／DLQ。RabbitMQ 中 `video.download`、`video.import`、`video.analysis-report`、`video.events` 及其 `.dead` 队列仍需相应受限角色权限；解析与分析队列已退出声明与消费，宿主 AI Worker 不再需要 RabbitMQ 账号。
- **可移植性**：业务 Compose 依赖已有基础服务；固定公开平台不依赖浏览器登录态，其余平台还依赖已运行、启用扩展并登录对应平台的 Chrome 来源。来源故障不阻止 broker 进程就绪，但会使对应操作明确失败。登录态、验证码、出口信誉与账号权益由第三方平台控制，不能由仓库恢复，也不承诺任意出口通过风控。
- **自部署更新**：先对现有库幂等应用 `schema.sql`，再配套更新 API／Worker／broker／Runner／Web，配置变化用 `up -d --build`，不以 `restart` 代替；更新前排空在途任务，不保留两阶段兼容或旧访问路线。内部会话协议变化须同时重建 broker 与 Runner；接口破坏性变更同步 Web 与 App。
- **密钥**：生产密钥检查只要求当前角色所需密钥；Import／Report／Outbox 不接收 URL 解密密钥，Worker 不接收 JWT、管理初始化及指标访问密钥。持久数据使用的 `URL_ENCRYPTION_KEY` 必须稳定并与数据库备份分开保管；会话中继使用 RPC 签名密钥，不再有平台 Cookie 数据库加密密钥。宿主机 agent 与业务容器必须显式选择同一环境配置；已有配置不得在启动时覆盖或重新生成。
- **可观测性**：日志不记录输入、凭据或上游错误文本；日志、指标、Provider 状态证据不含媒体 URL；系统操作日志见 [解析中心](06-解析中心.md)。
- **CI**：`Backend tests`（uv frozen、Ruff、strict MyPy、pytest、PostgreSQL 隔离 schema、Redis 租约）与 `Frontend tests`（pnpm frozen、Biome、tsc、Vitest、Next.js build）；OpenAPI 生成产物无漂移；CI 不能证明目标部署与真实平台可用，也不是强制合并门禁（当前 `main` 无分支保护）。

Temporal 为单容器四角色部署，PostgreSQL 的两个专用库持久化 History 和 visibility，命名空间首次连接时幂等创建，保留 7 天。按照[官方单节点配置说明](https://docs.temporal.io/references/configuration)，内部广播地址固定为 127.0.0.1，避免容器 IP 变化延长成员恢复；宿主访问端口仅绑定 loopback。此拓扑不是多节点高可用或互联网公开部署。API 历史读取不依赖 Temporal 在线，积压仍受业务配额和解析截止时间限制。

## 全平台解析运行目标（planned）

[设计 17](17-通用解析架构与实施计划.md)把故障定位扩展到认链、上下文、元数据、格式、媒体探测、传输、校验和发布；保留实际上游类别、最终媒体 host/port 与策略/上下文修订，不把所有失败改写为登录。复用现有冷却、Canary 和管理员诊断，按内容/会话/路线/依赖范围隔离故障，平台下载证据独立于 AI。

服务侧浏览器 Profile 持久保存，任务仍由 PG/Temporal/RabbitMQ 恢复；Browser Runtime 崩溃只影响对应能力。上下文变化须重新解析，不能通过无变化重试恢复；人工等待、实际策略调用和下载分片重试分别纳入同一业务预算。日志、诊断和 trace 的体积与保留期受本机容量限制，不新增运维平台或隐私合规门槛。
