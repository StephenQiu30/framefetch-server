## 3. 实施要求

恢复原 listAnalysisSkills(input_kind)、视频 createAnalysis(download_id)、文档 createDocumentAnalysis(document_id) 的业务语义。AnalysisRequest 保留 skill_id、zh-CN／en-US 和4000字 custom_prompt；目录含 display_name、description、default_prompt、input_kinds、result_contract。后端OpenAPI正式生成三端，不维护旧API别名或平行DTO。

使用完整源及固定方法／材料指纹。按任务加载专业模块，只读入知识，不继承上游工具权限。FFprobe、FFmpeg实帧、原文定位、引用校验、覆盖索引作内部工具，不建立新工具页或双源工作台。

先验证视频审阅／拆解和剧本分析。文章／渠道文档整理必须有实际结构与可读性改善，保护事实及Markdown；机械换行、包装字段或截开头不计完成。正式结果适合原reader，历史保持真实类型。未知回执、取消、Worker丢失遵守持久日志及fence，不自动再次推理。
