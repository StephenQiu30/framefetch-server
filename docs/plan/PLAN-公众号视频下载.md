# 公众号视频下载计划

依据[公众号视频下载 PRD](../prd/PRD-公众号视频下载.md)，技术规则见[解析引擎](../design/14-解析引擎.md#11-平台声明)与[解析意图](../design/06-解析意图.md)。

| 工作包 | 完成条件 | 状态 |
| --- | --- | --- |
| 原生视频解析 | 静态有界读取官方视频消息元数据，不执行页面脚本；绑定视频身份、官方 MP4、尺寸与时长 | 已通过消息与普通文章样本；未知模板仍按证据拒绝 |
| 选择与下载 | owner 与 TTL 校验后创建持久意图；重解析、格式确认、Worker、Artifact 共用现有流程 | 正式链路与 owner、TTL、幂等、配额回归通过 |
| 外链路由 | 腾讯视频与有效视频号分享链接使用各自 Provider 和内容范围 | 路由回归通过；真实文章外链完整交付未验证 |
| 三端交付 | Web 正式操作；桌面官方同步；App 白名单契约与对应入口更新 | Web 与 Electron 实际保存通过；App 设备集成未验证 |
| 平台验收 | 两部不同原生作品通过正式 API 的完整下载、规格、时长、哈希与全片解码；失败原样记录 | 两部原生作品通过 |

## 验证证据

原生专项证据位于 `artifacts/coldstart/20261009-dailymotion-wechat-fixed/matrix.json` 与 `matrix.md`（本机制品不入库）。匿名、无平台身份，使用正式发现、候选引用、持久意图、Temporal、下载队列与 Artifact 链路。

| 公开文章 / 视频身份 | 独立完整时长 | 交付文件 | 全片解码 |
| --- | --- | --- | --- |
| `bXUTSRQ_zIvyigWiqw3UfA` / `wxv_4601001312020021250` | 官方页面 992 秒 | 992.560181 秒，480×328，HEVC/AAC，13,534,685 字节 | 通过 |
| `JC0XgLZDFaxHhCv_G6ZAaw` / `wxv_4494939361800847365` | 官方页面 103 秒 | 103.677120 秒，480×270，HEVC/AAC，1,056,746 字节 | 通过 |

SHA-256、各音视频轨规格与解码结果保存在上述矩阵。Web 真实操作另交付第二部的 1920×1080 H264/AAC 文件（11,049,263 字节），浏览器保存、正式文件 HEAD 哈希比对与整片解码均通过；已覆盖桌面与 390px、明暗主题、键盘和溢出。Electron 从 `Wn1-SzjpEkQLTyZnJKDRwg` 的五个原生候选中选择第二项，经真实服务交付 16.717007 秒、1656×1080 H264/AAC 文件（604,203 字节）；原生保存窗口、制品哈希和整片解码均通过。

服务端测试 3662 通过、5 跳过；Web 648 通过。桌面同步、42 项单测与 10 项受控 E2E 通过，受控 E2E 不替代上述真实服务证据。App 冻结契约与选择入口已更新，分析与 400 项测试、Android debug APK 构建通过；iOS 通用模拟器构建在 Flutter 的 `lipo -verify_arch arm64 x86_64` 检查失败，同一源码的 arm64 模拟器 `xcodebuild` 通过。实际 App 登录、选择和文件保存尚未在设备验收。

## 未完成项

- App 的 Android/iOS 真实服务集成与本机文件保存。
- 腾讯视频和有效视频号分享链接在真实公众号文章中的端到端文件验收。
- iOS 通用模拟器 Flutter 工具链错误；arm64 构建成功不代表该命令通过。

本专项不代表全量平台矩阵、全部公众号模板或端侧设备验收通过。
